# 小红书做图提示词库（xhs-prompt-library）

把小红书信息图拆成 **9 个可组合维度**（形态 × 封面 × 排版 × 风格 × 主题色 × 尺寸 × 配色 × 字体 × 装饰），像选配方一样组合出图。纯静态网页，**双击 `index.html` 即用**，无需联网、无需密钥。

## 示例画廊（40 张真实出图，逐张目视校验）

## 出图怎么用

复制提示词（已自带 `1024×1536` 尺寸与硬约束）→ 粘到任意文生图工具出图。本库只出提示词，不代调模型。
