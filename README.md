# 小红书做图提示词库（xhs-prompt-library）

把小红书信息图拆成 **9 个可组合维度**（形态 × 封面 × 排版 × 风格 × 主题色 × 尺寸 × 配色 × 字体 × 装饰），像选配方一样组合出图。纯静态网页，无需联网、无需密钥。

## 🌐 在线使用（点开即用）

- **直连站点（国内推荐）**：<https://xhs-prompt-library.app.workbuddy.host/>
- **GitHub Pages（境外）**：<https://gaoren7716-lab.github.io/xhs-prompt-library/>

离线使用：下载仓库后双击 `index.html`。

## 怎么用

1. **示例画廊**：看中哪张直接点「复制提示词」，或点「合成器改用」在它的基础上改
2. **智能抽卡**：铺 1 / 4 / 8 组新组合，或掷骰「随机来一张」直接抽成品；**系列出图**：给一个主题（如「秋天」）自动建一组笔记图——封面/干货/佐证/收尾各一张，全组统一风格，每张带完整提示词，一键复制全部
3. **提示词合成器**：自己选 9 个维度实时拼装，派生位自动跟随
4. 复制的提示词已带 `1024×1536` 尺寸与硬约束 → 粘到任意文生图工具出图

其余页签：自定义出图（12 选题预设）、验证案例（5 个全文）、全部词条（80 条）、风格配色搭配（12 组）、框架与体检。
